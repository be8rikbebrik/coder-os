# 🚀 CODER-OS

**CODER-OS** — это специализированная операционная система для разработчиков и вайб-кодеров на базе **Arch Linux**, работающая "из коробки" на ноутбуках и ПК.

Главная фишка системы — **интерактивный мастер первичной настройки с красивым киберпанк-дизайном**, который перед установкой задает ключевые вопросы и конфигурирует систему под ваш стиль работы.

---

## ⚡ Выбор профиля перед установкой ("Кто ты?")

При загрузке с флешки вас встречает фирменный опросник CODER-OS:

| Профиль | Бейдж | Для кого и что входит |
| :--- | :--- | :--- |
| **Хардкорный Кодер** | `TERMINAL FIRST` | Максимум производительности, горячие клавиши, Neovim (LazyVim), Tmux, Zsh + Starship, C/C++, Rust, Go, Docker, Lazygit, Lazydocker, Btop. Никакого визуального мусора. |
| **Вайб-Кодер** | `AI & MODERN DEV` | Быстрый прототипинг, нейросети и современный веб/AI стек: VS Code, Python + uv, Node.js + Bun, Ollama (локальные LLM модели), Docker, Postman/Bruno, Aider. |
| **Линуксоид из коробки** | `OUT OF THE BOX` | Полноценный рабочий стол (KDE Plasma или Hyprland), браузеры, Telegram, Discord, LibreOffice, VLC, Flatpak, полная мультимедиа и офисная поддержка. |
| **Кастомный выбор** | `FULL CONTROL` | Тонкая ручная селекция каждого компонента и утилиты по категориям. |

## 🖥️ Скриншоты и Возможности

- **Графическое окружение:** Настроенный **Hyprland** (Wayland) с темной темой, размытием, эффектами свечения, статус-баром **Waybar**, меню приложений **Wofi** и терминалом **Kitty**.
- **Ноутбуки из коробки:** Автоматическая настройка Wi-Fi (NetworkManager), Bluetooth (BlueZ), Pipewire аудио, регулировка яркости (`brightnessctl`), мультитач-жесты тачпада.
- **Шрифты для кодинга:** JetBrains Mono Nerd Font, Fira Code, Noto Emoji.
- **Терминальные утилиты:** `eza` (вместо `ls`), `bat` (вместо `cat`), `ripgrep`, `fzf`, `fastfetch`, `lazygit`, `starship`.

## 🛠️ Как собрать ISO-образ

### Способ 1: Автоматически через GitHub Actions (Самый простой)
1. Создайте репозиторий на GitHub и отправьте в него эти файлы (`git push`).
2. Вкладка **Actions** автоматически запустит сборку в облаке на быстрых серверах Ubuntu.
3. Через ~10-15 минут готовый `.iso` файл появится во вкладке **Releases** или **Artifacts**.

### Способ 2: В Docker / Linux
```bash
sudo ./scripts/build-docker.sh
```

### Способ 3: В Arch Linux / WSL
```bash
sudo ./scripts/build-iso.sh
```

Готовый ISO-образ будет сохранен в папку `out/`.

## 💾 Запись на флешку и установка на ноутбук

1. Возьмите флешку объемом от 4 ГБ.
2. Запишите образ с помощью:
   - **[Ventoy](https://www.ventoy.net/)** (рекомендуется — просто скопируйте `.iso` на флешку);
   - **[Rufus](https://rufus.ie/)** (в режиме *DD-образ*);
   - **[BalenaEtcher](https://etcher.balena.io/)**.
3. Вставьте флешку в ноутбук, включите его и выберите загрузку с USB (обычно клавиши `F12`, `F11`, `F8` или `Esc`).
4. При входе в систему автоматически откроется мастер настройки **CODER-OS Wizard**.
5. Пройдите опрос, нажмите **«Начать установку»** и выберите диск в установщике Calamares!

## ⌨️ Горячие клавиши (Hyprland по умолчанию)

- `Super + Return` — Открыть терминал Kitty
- `Super + D` — Меню программ (Wofi)
- `Super + E` — Файловый менеджер (Thunar)
- `Super + I` — Запустить мастер настройки CODER-OS
- `Super + Q` — Закрыть активное окно
- `Super + Space` — Переключить плавающий режим окна
- `Super + Shift + M` — Выйти из графической сессии
